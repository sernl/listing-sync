# Teachouse 0.10.8 for Windows, Linux and Android

Copying or publishing a resource to a marketplace now completes in one pass. Before, a create whose answer was slow to arrive was left for a later turn and each resource could take twenty to thirty minutes; now the device waits for the marketplace inside the same turn, confirms the listing, and moves to the next resource within seconds.

A device that stops working on a resource before finishing now hands it back at once, so another turn picks it up immediately instead of after a ten-minute wait.

Update in place to retain marketplace sign-ins, device identity and kept originals. Do not uninstall or clear app data to update.
