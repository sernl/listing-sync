# Teachouse 0.10.5 for Windows, Linux and Android

Imports retain selected draft resources instead of skipping them before checking for files.
Resources with confirmed missing bundles can still arrive with their metadata; failed downloads remain visible errors.

Re-importing a locally deleted resource restores it without creating a duplicate.
Restored resources regain labels for their retained marketplace links.
Previous merges are respected, and re-importing an existing resource preserves your own title, description and files.
When a restored resource's original marketplace file has changed, its source-backed file record is refreshed without replacing your uploaded or additional files.

Permanent listing conflicts now finish with a visible item failure instead of leaving the import stuck committing.
Duplicate matching no longer uses the fingerprint of a file the resource did not accept.
Concurrent retries preserve completed import items and their history, including resources without files.

Fixes [RUSTSEC-2026-0187](https://rustsec.org/advisories/RUSTSEC-2026-0187), a PDF parser vulnerability that could abort an import on deeply nested documents.

On Android, returning to Teachouse wakes import discovery, including imports started from the browser.
Keep the app in the foreground while it reads your marketplace.

Update in place to retain marketplace sign-ins, device identity, catalogue data and import history.
