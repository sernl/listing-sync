# Teachouse 0.16.0

## PerfLogin

The sign-in, sign-up and password-reset pages now open in about a second on a slow connection, down from about three.

- The signed-out pages have their own light frame: none of the console's shell, query client, icon-heavy chrome, analytics or compiled rules load before the form, and nothing waits for the API before the first paint. Maintenance mode is checked right after that paint.
- Product analytics loads only after the page has finished loading and gone idle. On the signed-out pages it also waits for your first click or key press. The sign-in library loads when you submit.
- The fonts are content-hashed and cached for a year. The two used on the sign-in card are preloaded, and each sign-in page's own scripts are preloaded from the first byte, together with a connection to the security check.
- The PDF library behind the preview maker now loads only when you make a preview. The console's rules module now waits until the resource list has finished loading.

Measured with headless Chromium 153 on a cold cache, throttled to 1.5 Mbps down and 150 ms round trip. Each figure is the median of 5 runs. Prod is teachouse.io on 0.15.0. Local runs go through HTTP/2 with brotli, as prod does.

| Page | Before | After |
|---|---|---|
| `/login` first paint | 3.3 s (prod) | 1.17 s (1.08 s without the font preloads) |
| `/login` form typeable | 3.3 s (prod) | 1.16 s |
| `/login` script | 60 files, 412 KB (prod, incl. analytics and Turnstile) | 40 files, 65 KB on the wire (58 KB brotli bodies) |
| `/resources` first paint | 3.5 s (local, HTTP/1.1) | 2.4 s (local, HTTP/2) |
| `/resources` script | 306 KB | 154 KB |

Raw data: `/tmp/perf/before.json`, `/tmp/perf/after.json`.
