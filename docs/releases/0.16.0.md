# Teachouse 0.16.0

## TierLimits

- **Every plan now has a resource limit except Studio.** Look includes 100 resources (it was 500), Starter 500, Sync 2,000, and Studio has no limit. Prices are unchanged.
- **Watermarked previews are counted each month.** Look makes 5 a month, Starter 50, Sync 200, and Studio has no limit. The count starts again on the 1st of each month (UTC). Every preview a resource gains counts, whether it is made in the preview maker or dropped in as a file. Deleting a preview does not give one back.
- **If you already have more than your plan's new limit, you keep everything (the grandfather rule).** Nothing is removed, hidden or locked: you can still open, edit, publish and delete what you have. You can't add more resources until you upgrade or delete enough to be under the limit. The same holds for labels, templates, collections and storage. Preview counts start at zero on the day this ships, so nobody starts the month already used up.
- **The limit applies everywhere a resource can arrive.** A new resource, a spreadsheet row, an import from your shop, a resource moved from a device, a re-import that brings a deleted resource back, and undoing a merge all stop at the limit. When an import reaches it, the resources that fit arrive, and each one after that is marked as not imported with the reason. The rest of the import still finishes.
- **Other limits are now checked on every path.** Labels created by a spreadsheet import count toward your plan's labels. Covers and pictures from a shop import count toward your storage: a picture that would go over it isn't kept, and the resource arrives without it. Statistics are collected only on plans that include them. A plan that syncs less often now takes effect on the next sync, not only after you save your sync settings again.
- **Billing shows what you have used:** resources, templates, collections, labels, devices, and this month's previews against your plan, plus the date previews start again.
- **One sentence for a full plan, everywhere.** The disabled New resource button, the create form, an import row that didn't arrive and the preview maker all say what your plan includes and what you can do, e.g. "Your plan includes 100 resources. Upgrade to add more." Billing marks a used-up allowance as "full".
- The pricing page and the plan cards show the new limits. They come from the same table the server enforces.

Deploy: migration 0098 (`usage_counter`) runs on start. No backfill is needed, because preview counts start at zero.
