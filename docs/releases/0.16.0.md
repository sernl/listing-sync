# Teachouse 0.16.0

## Feedback

- **Connecting TPT or TES works on Windows.** The app used to put the whole marketplace login in Windows Credential Manager, which refuses anything longer than 2560 characters, so connecting failed with "the session store refused: Attribute password encoded as UTF-16 is longer than platform limit of 2560 chars". Every platform now keeps the login sealed (XChaCha20-Poly1305) in a file in the app's own data folder, and the operating system's credential store holds only the 32-byte key that opens it. A login an earlier version kept in the credential store moves into the file the first time the app reads it, so nobody is signed out by the update.
- **The tour ends on getting the app.** In a browser, the last card is **Start here: download the app**, with a button to the Get-the-app step on Marketplaces. In the app it still ends on **Create your first resource**.
- **A short tour the first time you open the app.** Three cards on each new device: marketplaces are connected here, in the app; open Marketplaces and press Connect; importing, distributing and managing work in the app or in your browser. It is shown once per device.
- **Catalogue → Files.** The Catalogue tab "Your devices' files" is now called **Files**, in the navigation, the page title and the guides.
