# Teachouse 0.9.0 for Windows and Android

This beta repairs catalogue imports, device connections and Guides. Update the app before importing or publishing resources whose files are held on a marketplace.

## Imports and publishing

- TES and TPT imports can run independently. Starting the same source twice opens its existing import rather than creating another one.
- Import progress distinguishes discovery, selection, reading, review and interruption. A connected page no longer implies that its device is still working.
- Stop and resume preserve the import's recorded work. A stop queued while the device is offline is replayed after reconnection, while stale responses from an earlier attempt cannot overwrite a resumed import.
- Catalogue additions require your confirmation. Duplicate checks run again before committing an addition.
- TPT's own-file download joins the device-local file path used by TES. Imported originals stay on your device; Teachouse records file evidence rather than uploading those originals to its server.
- Publishing still checks the actual files, source sessions and destination requirements. Importing a title and description alone does not make a resource ready to publish.
- Migration previews now refuse a paid resource priced in a different currency from the destination. Change the catalogue price explicitly instead of confirming work that can only stop on a currency gate.
- A successful device create or removal is recorded with its terminal event before its lease is released, so completed work no longer appears abandoned on the phone.

## Connections and startup

- A marketplace signed in on another machine no longer hides Connect on this device.
- Sign out on this device and disconnect from your account are separate controls. Account disconnect does not erase logins saved on your other machines.
- TES sign-in completes only after TES recognises the seller identity. An anonymous session cookie is no longer reported as a connected seller account, and overlapping sign-in windows cannot replace a later successful capture with an earlier result.
- The app opens the hosted console from a local connection page. If the workspace cannot be reached, Retry remains available instead of leaving a broken local copy of the console on screen.
- Startup checks entitlement before reclaiming persisted imports, so a briefly closed gate cannot strand existing work.

## Guides

- Operator drafts are separate from published guides. Autosave preserves working edits without exposing them to readers.
- The editor supports a live preview, images, topics and tags, with explicit publishing.
- Readers can search published guides and combine topic and tag filters. The address preserves the current search and filters.

This is a coordinated app and server update. Older apps cannot execute marketplace-sourced file work against the new server. Existing catalogue data and import history are retained.
