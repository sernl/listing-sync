# Teachouse 0.10.7 for Windows, Linux and Android

On Android, a phone that opened Teachouse while locked no longer keeps no originals for the rest of that session. The kept-files library now opens on the first use after the phone is unlocked, and every check-in retries it, so imports keep originals as soon as the device can seal them.

Opening a console page such as Automations → Mappings directly by its address now shows the page instead of an API answer.

An import that reaches review after an earlier device interruption no longer shows that earlier condition as a current problem; it is listed under Technical details.

Update in place to retain marketplace sign-ins, device identity and kept originals. Do not uninstall or clear app data to update.
