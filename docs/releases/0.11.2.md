# Teachouse 0.11.2

Moves replace the monthly migration cap: packs are a balance valid twelve months, Sync accrues 25 a month to 75, and the free plan holds five lifetime moves per shop. Billing runs on Stripe (checkout, portal, webhook); Paddle is gone. A shop binds to one Teachouse account: the app now reports the marketplace's own seller id on check-in, and a second account naming the same shop is refused. PostHog telemetry behind the site's own `/ingest`, off until a key is set. Console wording cut to one sentence per surface, seventeen guides with screenshots, navigation renamed, icons on actions, mobile-first layout, and a "Plan and moves" page with checkout. Server migrations 0084–0086; desktop wire gains an optional `external_id` on heartbeat sessions.
