# Teachouse 0.2.0 for Windows

This is the beta that follows 0.1.3.
It is still a beta, so expect rough edges, and please say what you find.

## What you can do with it

The app can now fetch a listing's files from Tes, under your own Tes login, when a sync order names them.
Before this, every file an upload needed had to come from us; a file you already sell on Tes can now come from Tes instead.
This is groundwork rather than something to try today, because what would ask for those files is the catalogue import, and that ships in the next release.
Your Tes session stays at Tes while it happens.
Tes hands the download off to another host, and the app re-issues that one hop on a connection carrying nothing of yours, so the cookie that proves who you are is never sent anywhere but Tes.
The same is not yet true of TeachersPayTeachers, and the app refuses a TPT file download rather than guessing at one.

A captcha or an interstitial met while the app is creating a listing no longer stops the rest of your queue.
That one item is held while everything else carries on, and the app goes back to the marketplace to find out what actually happened before it touches the item again.
The same now happens when a submission goes out and the marketplace's answer is unclear.
The console shows such an item as waiting on an answer from the marketplace and links to the run it came from; there is nothing for you to do while it waits.
When the app goes back to find a listing it is unsure it created, it looks for it by its title, so nothing Teachouse does writes a marker into your listing.

The app now tells us which marketplaces it is signed in to, on every check-in rather than only when you sign in.
It sends the fact that a session is held and never the session itself.
The console reads a marketplace as connected from those check-ins, so what it shows is what this machine can actually do right now.
Your declaration that you are the author of what you sell is kept against your account rather than against this device, so it survives a reinstall or a move to another computer.
Teachouse will not write to TeachersPayTeachers at all until you have made that declaration, and it refuses before any request leaves your machine rather than after one.

Before it works a marketplace, the app checks that your subscription covers it and that you have not signed this device out from the console.
When that check fails and nothing had gone out yet, the item is put back untouched rather than recorded as an attempt.

Work whose files come from a marketplace is only sent to a copy of the app new enough to handle it, and 0.2.0 is the first one that is.
An older copy is not offered such an item at all, and the console says the item is waiting for a newer version of the app rather than showing it as failed.

Editing a TeachersPayTeachers listing no longer clears its "Appropriate for" box, the one TPT labels with your account's country.
The app reads that box off your own upload page and reposts what it finds, and a new listing carries whatever answer you gave.
You can also leave that answer unstated, and nothing is stored for it until you give one.

The built-in console has changed too, and because it is packaged inside the installer, updating the app is how you get these.
You can point Teachouse at a listing you already have by pasting its address, one at a time or a batch at once, and nothing is asked of the marketplace to do it.
Every listing Teachouse knows about now carries a link to its live page, which the listed chip opens.
A new Templates screen lets you say how your own categories should be read, with "Same as" and "Belongs under", and those choices apply to your account alone.
If you use the console in a browser, you already have all of this; it is the app that needed the update to catch up.

One caveat carried over from the last release.
The file fetch described above has not run against a real catalogue yet, because nothing asks it to until import ships.
Check what a run did before trusting it unattended.

## Updates

Whether you are on 0.1.3 or on 0.1.1, install this version by hand, once.
Neither build ever checks for a new version, so neither can fetch this one on its own, and 0.1.1 additionally points at an update address that never answers.
Download the installer below and run it over your existing installation.

From 0.2.0 on, this stops being something you do.
The app checks for a new version each time it opens and installs it before it starts working.
It checks the beta channel, which is where this release and the ones after it are published.

## Installing it

Download the `-setup.exe` installer and run it.
The `.msi` beside it installs the same application and exists for anyone who has to deploy it through Windows Installer.

Windows will warn you that the publisher is unknown.
That is expected for now: this build is not yet signed with a code-signing certificate, and the warning will go away in a later release.
The `SHA256SUMS.txt` file lists the checksum of each installer if you want to verify the download.
