# Teachouse 0.17.0

## Polish

- **Download buttons on Marketplaces.** Download for Windows, Linux and Android now fetch the file. The console treated the `/downloads/…` link as one of its own pages and showed "That page is not here"; the buttons are now marked as downloads, so the browser fetches the file from the server.
- **Admin Pricing theme.** A sale's Theme list now offers every site theme the Site page offers (16 and No theme), and the server accepts any of them.
- **Admin Mail empty state.** The New email button no longer sits on the sentence above it. Every empty state with a button gets the same gap.
- **Home page.** The header's Start free button now darkens on hover like every other primary button. The free app box says why the app exists (TPT and Tes have no official API) in two sentences, and the house mark above the console screenshot is gone.
