# Teachouse 0.17.0

Sync is now called Pro, each plan's resource and preview limits change, and Billing counts what you have really used. Pop-ups are coloured and kept behind a new bell with a count of what is unread, a TPT import fills its Tes licence, and the help guides publish themselves on every deploy.

## Polish

- **Download buttons on Marketplaces.** Download for Windows, Linux and Android now fetch the file. The console treated the `/downloads/…` link as one of its own pages and showed "That page is not here"; the buttons are now marked as downloads, so the browser fetches the file from the server.
- **Admin Pricing theme.** A sale's Theme list now offers every site theme the Site page offers (16 and No theme), and the server accepts any of them.
- **Admin Mail empty state.** The New email button no longer sits on the sentence above it. Every empty state with a button gets the same gap.
- **Home page.** The header's Start free button now darkens on hover like every other primary button. The free app box says why the app exists (TPT and Tes have no official API) in two sentences, and the house mark above the console screenshot is gone.

## Guides

The help guides now publish themselves on every deploy. After the migrations, the deploy step checks that every picture a guide names is in `docs/guides/images/`, seals the pictures straight into the blob store (`tam-admin guides images`, no operator session or running server needed), then seeds the guides (`tam-admin guides seed`). Both writes are idempotent: the same picture bytes are the same handle and are not stored twice, and a guide whose file has not changed is not re-published, so a deploy with no guide changes writes nothing. On a new deployment with no operator yet, the pictures are placed and the text waits for the next deploy.

- `tam-admin guides check --dir docs/guides` (and `just guides-check`) proves, without a database, that the guides and their pictures are one set.
- The migrations package now carries the guides under `guides/`; the NixOS module runs them in a `teachouse-guides` unit as the API's user, and the cluster's migrate Job gains the blob key and store credentials.
- The plan guides use this release's names and figures: Pro in place of Sync; resources Look 100, Starter 250, Pro 500, Studio unlimited; watermarked previews Look 5 in all, Starter 20, Pro 50 and Studio 100 a month; Pro templates and collections 10 each; AI fill on Pro and Studio.

## ImportLicence

- **Tes licence from TPT's copyright statement.** A resource imported from TPT used to open with its TPT answers filled and the Tes licence on "Choose a licence". Where the seller lists on Tes too (signed in to Tes, or the resource is mapped there), the import now fills the Tes licence from the resource's TPT copyright statement: a priced resource gets `TES-PAID`, the only licence Tes takes with a price; a free resource that is the seller's own original work gets Tes's own default, `CC-BY-SA`; a free resource that uses material the seller has permission to use gets `CC-BY-ND`. Fill-only: a licence the seller picked is never replaced. **Refresh** on a finished import fills it for resources imported before this release, or once Tes is added later.
- **Tes imports keep their licence selectable.** A Tes listing carrying a legacy `TES-V1`/`TES-V2` licence is stored as `CC-BY-SA`, which is what Tes's own editor turns them into, so the licence box is no longer empty on the marketplace the resource came from.
- **"Filed under" names every marketplace.** The band under a resource used to show only the import's mark, so a TPT import that was also ticked for Tes showed TPT alone. It now lists every marketplace the resource is mapped to, from the left edge under the heading, each with its mark, name and state (Listed, Draft, Not sent yet, Sign-in needed …), then the seller's own labels and collections.

## Usage

- **Billing shows what you have really used.** Every figure in "What you have used" is counted live from the record: resources you have not deleted, marketplaces connected, templates, collections, your own labels, devices not signed out, watermarked previews made, and moves used this month. The page used to show the figures from when you first opened the console, so a shop imported or a preview made since then read as "0". It now reads them again every time it opens.
- **Previews made before 0.16.0 now count.** The preview counter started at zero when it shipped, so previews made earlier read as "0 watermarked previews". They are counted from your resources' preview files, deleted ones included, and a month already counted is never lowered.
- **Usage is a table.** Each row says what you used, what your plan includes and what is left, with a thin bar and the day a monthly count starts again. On a phone each row becomes a small card.
- **What is a move?** A yellow box at the top of the plans, on Billing and on the pricing page, says it in one sentence, with Explain for the rest.
- **Move Packs table.** The Moves, Price and Per move columns line up under their headings, and every row is the same height.

### Plans

- **Sync is now called Pro.** Same price, same plan. Nothing changes for anyone already on it.
- **Look:** 5 watermarked previews for the life of the account, not 5 a month. They don't come back when the month turns.
- **Starter:** up to 250 resources and 20 watermarked previews a month. AI description fill is no longer listed on Starter.
- **Pro:** up to 500 resources, 50 watermarked previews a month, 10 templates and 10 collections.
- **Studio:** 100 watermarked previews a month. Resources, templates and collections stay unlimited.
- If you already have more than a new limit allows, you keep everything. You can't add more until you upgrade or make room.

### Deploy

- Migration 0101 backfills the preview counter from existing preview files. It runs on start and changes no month the counter already holds a higher figure for.
- `just web-typegen` output is committed (`web/src/lib/generated/*`, `apps/landing/src/plans.generated.js`).
- **Stripe (integrator):** rename the product behind `sync_monthly` / `sync_yearly` from "Teachouse Sync" to "Teachouse Pro". The price keys and amounts do not change.

## Notify

- **Coloured toasts.** Every pop-up is coloured by what it says: green for a save, blue for information, amber when something was refused or needs a look, red for an error. They stack at the top right (across the top on a phone), at most three at once, and each goes after five seconds. Hovering or focusing one holds them; the close button, Escape and reduced motion all work as before.
- **Nothing missed.** A pop-up that went while you were looking elsewhere is kept in your notifications. One you closed or clicked is not.
- **The bell.** A bell sits between New resource and your account picture, the same size, with a count of what is unread. It opens the newest twenty with Mark read and Dismiss on each, Mark all read, and a link to the full page. On a phone it sits in the page header and opens as a sheet from the bottom.
- **Notifications page.** Each row carries its colour; unread rows are bold. Mark read and Delete per row, Mark all read and Delete read for the lot. The page no longer marks everything read just by opening it. Its heading and its Account menu entry now show an inbox rather than a second bell, so a phone's header carries one bell.
- **Finished runs** come in coloured by how they went: red if anything failed, amber if anything needs a look, green otherwise.

Deploy: migration `0100_notification_notice` runs on start (adds notice columns to `notification`, and widens its row policy to the user). New routes: `POST /v1/notifications`, `POST /v1/notifications/{id}/read`, `POST /v1/notifications/read-all`, `POST /v1/notifications/dismiss-read`, `DELETE /v1/notifications/{id}`; `GET /v1/notifications` now answers `unread` and a `source`/`tone` on each row.
