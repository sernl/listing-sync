# Teachouse 0.17.0

## Guides

The help guides now publish themselves on every deploy. After the migrations, the deploy step checks that every picture a guide names is in `docs/guides/images/`, seals the pictures straight into the blob store (`tam-admin guides images`, no operator session or running server needed), then seeds the guides (`tam-admin guides seed`). Both writes are idempotent: the same picture bytes are the same handle and are not stored twice, and a guide whose file has not changed is not re-published, so a deploy with no guide changes writes nothing. On a new deployment with no operator yet, the pictures are placed and the text waits for the next deploy.

- `tam-admin guides check --dir docs/guides` (and `just guides-check`) proves, without a database, that the guides and their pictures are one set.
- The migrations package now carries the guides under `guides/`; the NixOS module runs them in a `teachouse-guides` unit as the API's user, and the cluster's migrate Job gains the blob key and store credentials.
- The plan guides use this release's names and figures: Pro in place of Sync; resources Look 100, Starter 250, Pro 500, Studio unlimited; watermarked previews Look 5 in all, Starter 20, Pro 50 and Studio 100 a month; Pro templates and collections 10 each; AI fill on Pro and Studio.
