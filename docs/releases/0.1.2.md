# Teachouse 0.1.2 for Windows

This is the first published beta of the Teachouse desktop client.
It is a beta, so expect rough edges, and please say what you find.

## What you can do with it

Sign in to TeachersPayTeachers and to Tes without leaving the app.
Each marketplace opens in its own login window and you sign in exactly as you would in a browser.
Your password and your marketplace session stay on your computer; neither is sent to us, and neither is stored on our servers.

Leave the app running and it works to a schedule, hourly by default.
Every request Teachouse makes to a marketplace is made from your machine, under your own login, the same way it would be if you were clicking through the site yourself.

The console is built in.
It is the same dashboard you would use in a browser, running inside the app window.

One honest caveat while this is a beta.
Publishing from your own device is new, and its first live run against real stores has not happened yet.
Expect the schedule and the console to work; treat publishing as still under verification, and check what it did before trusting it unattended.

## Updates

Teachouse now checks the beta channel for new versions, which is where this release and the ones after it are published.
From this version on, updates arrive on their own.

If you already installed 0.1.1, you have to replace it by hand, once.
That build shipped pointing at an update address that never answers, so it cannot fetch this release itself.
Download the installer below and run it over your existing installation; updates will work normally from then on.

## Installing it

Download the `-setup.exe` installer and run it.
The `.msi` beside it installs the same application and exists for anyone who has to deploy it through Windows Installer.

Windows will warn you that the publisher is unknown.
That is expected for now: this build is not yet signed with a code-signing certificate, and the warning will go away in a later release.
The `SHA256SUMS.txt` file lists the checksum of each installer if you want to verify the download.
