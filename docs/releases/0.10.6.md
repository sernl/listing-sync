# Teachouse 0.10.6 for Windows, Linux and Android

On Android, Open in Files now hands a kept original to an installed viewer with read-only access, instead of failing before the viewer opens.

Resources now has a Files page with search, filters, pagination, machine views and links to the resources that use each file.
Machine sign-ins are in Settings → Preferences, below Browser sign-ins.

Import and crosslist history support search, filters, pagination, and single or bulk deletion.
Deleting an active history record stops future work before hiding it; resources, original files and marketplace listings are kept.
Work already being sent may finish before the stop takes effect.

Update in place to retain marketplace sign-ins, device identity and kept originals. Do not uninstall or clear app data to update.
