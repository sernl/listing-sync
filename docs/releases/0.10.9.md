# Teachouse 0.10.9 for Windows, Linux and Android

Tes sessions no longer lapse while the app is signed in: the device keeps the session renewed on every check-in, adopts the cookies Tes rotates on each reply, and reports a marketplace as signed out the moment Tes stops recognising it, before any resource is attempted.

Uploading a resource's files to Tes is given the time a real bundle needs, so a create no longer times out and wait to be found again.

A resource whose earlier attempt was blocked can be queued again.

Update in place to retain marketplace sign-ins, device identity and kept originals. Do not uninstall or clear app data to update.
