# Teachouse 0.10.10 for Windows, Linux and Android

Creating a resource on Tes no longer pauses to search for a listing the create already named: when Tes is slow to show a freshly uploaded draft, the device waits for it by its identifier instead of treating the write as lost. A resource now takes roughly as long as its files take to upload.

Update in place to retain marketplace sign-ins, device identity and kept originals. Do not uninstall or clear app data to update.
