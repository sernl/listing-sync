# Teachouse 0.8.0 for Windows and Android

This is the beta that follows 0.7.1.
It is still a beta, so expect rough edges, and please say what you find.

Two things stand out: there is now a Guides section with written help you can read from any page, and the people who run Teachouse can see who is signed in and help you from the back office.

## Guides

The Guides page is no longer a placeholder.
Every signed-in seller can read the published guides, one page per guide, with pictures and tables where they help.
The question-mark button on every page opens the guides.

## For operators

- **Users** lists every account with its organisation, current plan, when it last signed in and how many places it is signed in from, with the plan dialog on the row and a Sign out everywhere button for an account that needs it.
- **Guides** has an editor: Markdown with a small toolbar, picture insert, a Published switch and a preview of the last saved version.
- A guide body is rendered on the server and any HTML written into it is shown as text, never run.

## For developers

- `GET /v1/admin/users`, `GET|POST /v1/admin/guides`, `GET|PUT|DELETE /v1/admin/guides/{slug}`, `POST /v1/admin/guides/images`, `GET /v1/guides`, `GET /v1/guides/{slug}`, `GET /v1/guides/images/{handle}`.
- Migration 0073 adds the global `guide` table.
- The identity-admin marking that opens the users page's session tools is a runbook step: `docs/notes/runbooks/operator-markings.md`.

The desktop and Android clients render the hosted console, so this release changes nothing in the client beyond the version.
