# Teachouse 0.19.1

## Launch hardening

- **Cloudflare Web Analytics reports again.** The edge injects its beacon into every page on both hosts, and both content-security policies refused the beacon's report, which logged an error in every visitor's browser console. `connect-src` on the landing policy (`serving.rs` `landing_policy`) and the console policy (`main.rs` `console_policy`) now names `https://cloudflareinsights.com` (`serving::BEACON_ENDPOINT`), and nothing else was added. The console policy also gains `frame-ancestors 'none'`, which the landing policy already had.
- **Security headers on every answer.** tam-server now sends `Strict-Transport-Security: max-age=31536000; includeSubDomains`, `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Permissions-Policy: camera=(), microphone=(), geolocation=()` and `Referrer-Policy: strict-origin-when-cross-origin` on every response from every tier, including the API, downloads and the maintenance page (`serving::transport_headers`, the outermost layer in `assemble`). Guide pages keep their stricter `Referrer-Policy: no-referrer`. Before this, only the CSP came from the origin.
- **Signing in returns you to the page you asked for.** A signed-out visit to a console address now goes to `/login?next=<path and query>` instead of a bare `/login`. Signing in lands on that page rather than on the home page. The login page also stores the destination in the sign-up intent, so a new account that returns through `/login` in the same browser goes there too. `safeNext` now asks the URL parser whether `next` stays on this origin, so `/\host` is refused along with `//host`.
- **The help guides are public.** `/guides` and every guide under it open without signing in (`PUBLIC_SECTIONS` in `web/src/lib/nav.ts`), and so the pricing page's FAQ links reach the guide they name. The API serves `GET /v1/guides`, `/v1/guides/_taxonomy`, `/v1/guides/{slug}` and `/v1/guides/images/{handle}` without a session. These routes return only published guides and their pictures, never drafts or organisation data. Every `/v1/admin/guides*` route still requires an operator session. A signed-out reader does not see "Show me around".
- **The marketing site has its own home-screen icon.** `apps/landing/public/apple-touch-icon.png` is the console's 180×180 icon, so `https://teachouse.io/apple-touch-icon.png` no longer redirects to dash. `nix/landing.nix` fails the build if the file is missing.

Deploy: no migrations and no new configuration. Before shipping, make sure nothing under `teachouse.io` is served over plain HTTP: `includeSubDomains` makes browsers refuse it for a year.
