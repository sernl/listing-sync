# Teachouse 0.7.0 for Windows and Android

This is the beta that follows 0.6.0.
It is still a beta, so expect rough edges, and please say what you find.
Two things stand out: a template can now hold every answer on the new-resource form and be applied to many resources at once, and collections let you gather resources into an ordered list you can act on.
Everything in this release reaches you from the server, so a browser has it the moment it is published; 0.7.0 is the app build that carries the same console, with nothing new inside the app itself.

## What changed in the app

Nothing changed inside the app for this release beyond the version.

## What changed in the console

A template holds the whole form.
The Template Manager's New resource tab now shows every band of the new-resource form, description, price, categories, standards, details and status, plus a name, a note to yourself, and who it is written for: any marketplace, Tes or TPT.
A template written for one marketplace also holds that marketplace's own questions, such as TPT's copyright, tax code and localisation.
Every field is optional: what you leave empty is asked as usual.

A new resource can start from a template.
At the top of the new-resource form, Start from a template fills the fields you have not yet answered, tells you which ones it filled, and offers Undo.

A template can be applied to many resources.
Tick resources on the Resources board and choose Apply a template, or apply one to a whole collection.
Preview shows one row per resource: Will change with the fields it would fill, Unchanged, or Blocked with the reason.
Only empty fields are filled unless you tick Overwrite; the title is never touched.

The sync rule can fill new pulls from a template.
On Marketplace Sync, each pull card offers a template that fills what the pull left empty before the resource is published onward, which is how a Tes pull gains the TPT answers Tes never asked for.

Collections.
Under Crosslist, Collections is an ordered list of resources with a name and a description.
Add resources from a checklist, reorder them, remove them; removing one takes it out of the collection and nothing else.
Three actions work on the whole collection: Publish to a marketplace, with the same per-resource preview Migrations uses; Apply a template and labels; and Export, a spreadsheet of the collection alone.
On the Resources board, Add to collection files your ticks into an existing or a new collection, and a resource's own page lists the collections it is in.
Your plan sets how many collections you can hold.

## Known limitations

A resource live on Tes cannot yet have a template applied, because Tes's edit of a published listing is not yet captured; the preview says so on each such row.
The same rule already applies to editing such a resource by hand.

A collection's Publish sends resources that are not already on the marketplace; a delist action for a collection is not built.

A template written for a marketplace holds that marketplace's answers on the resource itself; per-marketplace wording that differs from the catalogue's is still the Marketplace words tab.

Email about a finished run is not yet being sent.

There is no browser extension for Chrome or Firefox, and no Apple build.
No marketplace beyond Tes and TPT is connected.
The privacy and terms pages are still drafts.

## Updating

If you are on 0.6.0 on Windows, this arrives on its own.
The Android app does not update itself; download the package from this release and install it over the one you have.
The console needs no update at all.

## Installing it

Windows will warn you that the publisher is unknown.
That is expected for now: this build is not yet signed with a code-signing certificate, and the warning will go away in a later release.

## For operators

Migration 0072 adds `resource_template.description` and `resource_template.scope`, `auto_publish_rule.template_id`, and creates `collection` and `collection_member` under forced row-level security; the tenant matrix grows to fifty-eight tables.

Routes land at `POST /{version}/templates/{template}/apply/plan` and `/apply`, under `/{version}/collections`, and `GET /{version}/products/export` takes `?collection=` or `?products=`.

`collections` joins the reserved organisation slugs, the fifty-sixth.
