# Teachouse 0.10.4 for Windows, Linux and Android

Teachouse moves to https://teachouse.io. Sign in again on the new domain after updating. Account notifications come from no-reply@notify.teachouse.io.

Imports retain queued pages through temporary server failures and pause after repeated submission failures instead of retrying indefinitely. Resuming retries the saved work. A page the server permanently rejects now fails the run with a visible reason rather than starting the same attempt again. Import failures also retain their retry delay when the work queue is idle.

Terminal failures saved by earlier versions are delivered without starting another marketplace read. Queued failure reports can recover an expired lease without taking a run from another device.

Server-side recovery keeps the failure reason visible until work advances. The storage routing and credentials that blocked TES description uploads have also been repaired.

Marketplace sign-ins, catalogue data and import history are retained when updating from 0.10.2. Version 0.10.3 was not distributed; this release includes its changes.
