# Teachouse 0.10.18

Fix: an import resolves untagged native ids through the seeded relation. The TPT reader tags nothing by design (its facets are one flat namespace), but the inbound projection only read tagged axes, so every TPT import landed with no subject, no resource type and no grade and Tes refused to publish it. Subjects, topics, resource types and phases now come from whichever source axis the relation binds the id to. Server only; no migration. Existing products pick this up on re-import.
