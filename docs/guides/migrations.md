# Moving a shop to another marketplace

A migration takes resources you already sell on one marketplace and commits them to another.

## Before you start

1. Connect both marketplaces.
2. Import the shop you are moving from.
3. Say who holds the copyright — see [Who holds the copyright](/guides/copyright).

## Run a preview

1. Open **Automations → Migrations**.
2. Choose the shop to read and the marketplace to move to.
3. Preview the plan and read every row.

A preview queues nothing and costs nothing.

## Copy or move

- **Copy** leaves the original listing where it is.
- **Move** takes the original down after the new listing is live.

Pick copy if you are unsure; you can take the original down later.

## What it costs

One resource committed to the other marketplace is one move, counted when you commit it and after duplicates are merged. A draft costs the same as a live listing. Read [Your plan and what it allows](/guides/plans) for where moves come from.

## When it starts

A migration starts at the next device check-in, so leave the desktop app signed in. Watch progress under **Automations → Migrations**.

## What blocks a row

- No target price. Set one under [Setting target prices](/guides/target-prices).
- A word the marketplace does not offer. Answer it under **Unmatched words**.
- No file on any signed-in machine.
- Not enough moves.

Fix what a row names and run the migration again; rows already committed are not committed twice.
