# Moving a shop to another marketplace

A migration takes resources you already sell on one marketplace and publishes them on another.

## Before you start

1. Connect both marketplaces.
2. Import the shop you are moving from.
3. Say who holds the copyright. See [Who holds the copyright](/guides/copyright).

## Preview first

1. Open **Automations → Migrations**.
2. Choose the shop to move from and the marketplace to move to.
3. Preview the plan and check every resource in it.

A preview sends nothing and costs nothing.

## Copy or move

- **Copy** keeps the original listing where it is.
- **Move** takes the original listing down once the new one is live.

If you are unsure, pick Copy. You can take the original down later.

## What it costs

Each resource you publish on the other marketplace is one move. It counts when you publish, after duplicates are merged. A draft costs the same as a live listing. See [Your plan and what it allows](/guides/plans) for how you get moves.

## When it starts

The migration starts as soon as your desktop app is running and signed in, so keep it open. Follow progress in **Automations → Migrations**.

## What holds a resource back

- It has no target price. Set one in [Setting target prices](/guides/target-prices).
- It uses a word the marketplace does not offer. Answer it in **Unmatched words**.
- None of your signed-in computers has its file.
- You do not have enough moves.

Fix the problem shown and run the migration again. Resources already published are not published twice.
