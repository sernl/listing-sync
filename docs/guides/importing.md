# How importing works

An import brings listings you already sell into your Teachouse catalogue. Nothing is sent to a marketplace by an import.

## Import from a marketplace

1. Connect the marketplace first, then open **Import**.
2. Pick the shop to read and start the import.
3. Leave the desktop app running until the run finishes.

## Import from a spreadsheet

1. Choose your file on **Import** and upload it.
2. Read the report before you accept anything: it shows what your sheet said and what will be created.
3. Tick the rows you want and create them.

Every row that names a marketplace needs the fields that marketplace asks for. A row missing one is listed as needing an answer, and you can fix it in the sheet and upload again.

## Files come separately

An import records what a listing says, not the file a buyer downloads. Attach files from the machine that holds them — see [Where your files live](/guides/your-files).

## When a run stops

- **Given up** means we tried a row enough times and stopped. Fix what it names and run the import again.
- **Expired** means the run waited too long for a device to pick it up. Sign in on the desktop app and start it again.

## Check the result

1. Open **Catalogue → Resources** and search for a title you expect.
2. Open the resource and check the marketplace it came from is listed.
