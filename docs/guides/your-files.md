# Where your files live

Your listing files stay on your own machines. Teachouse records which machine holds which file and sends a file only when you publish to a marketplace.

## See which machine holds a file

1. Open **Catalogue → Your machines' files**.
2. Search for the resource.
3. Read the machine name beside each file.

## Add a machine

1. Install the desktop app on the second machine and sign in.
2. Leave it running once so it reports the files it can see.
3. Refresh **Your machines' files**.

## Move a file to another machine

1. Copy the file across yourself, keeping the same name.
2. Open the desktop app on the new machine.
3. Check the resource lists the new machine before you publish.

## Publishing needs the machine awake

A publish waits for a machine that holds the file. Keep that machine on and signed in while a run is going.

## Deleting

Removing a resource in Teachouse removes the record, not your file. Delete the file yourself if you want it gone.

## The one exception

A thumbnail is stored by Teachouse so the console and the marketplace can show it without waking your machine. Everything a buyer downloads stays with you.
