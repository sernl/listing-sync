# Exporting your catalogue

An export is a spreadsheet of your catalogue that you can open anywhere.

## Export everything

1. Open **Catalogue → Export**.
2. Choose what to include.
3. Build the file and download it.

## Export one collection

1. Open the collection.
2. Choose **Export**.
3. Download the file.

The rows come out in the collection's order. See [Labels and collections](/guides/labels-and-collections).

## What is in the file

One row per resource, with a status column saying where it stands on each marketplace. Details only: no file a buyer downloads is included, and no preview.

To get your files, copy them from the machine that holds them — see [Where your files live](/guides/your-files).

## The file name

Each file is named for your catalogue and dated in UTC, so files sort in the order you made them and two exports on the same day do not overwrite each other.

## Built when you ask

The file is built when you ask for it and is not kept. Ask again for a fresh one after you have changed something.
