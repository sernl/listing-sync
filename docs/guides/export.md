# Exporting your catalogue

An export is a spreadsheet of your catalogue that you can open anywhere.

## Export everything

1. Open **Catalogue → Export**.
2. Choose what to include.
3. Create the file and download it.

![Building an export](/v1/guides/images/9ee2537658c7158112464438c5399516b7dfe397c3650e4a3ddc70e1496d7cb3)

## Export one collection

1. Open the collection.
2. Choose **Export**.
3. Download the file.

Resources are listed in the same order as the collection. See [Labels and collections](/guides/labels-and-collections).

## What is in the file

Each resource gets one line, with a column that shows where it stands on each marketplace. The file holds details only. It does not include the files buyers download or any previews.

To get your files, copy them from the computer that has them. See [Where your files live](/guides/your-files).

## The file name

Each file is named after your catalogue and dated in UTC. Your files sort in the order you made them, and two exports on the same day do not overwrite each other.

## Made when you ask

Teachouse makes the file when you ask for it and does not keep it. After you change something, export again to get an up-to-date file.
