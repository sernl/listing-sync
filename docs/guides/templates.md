# Templates

A template is a set of answers you give the same way each time, such as the description layout, the price, the subject and the licence. It fills them in on a resource so you don't type them again.

A template never sets the title, the files or the pictures. Those belong to each resource.

## The three steps

Open **Catalogue → Templates**. The **Resource templates** tab works in three steps, shown across the top: **Pick**, **What it sets** and **Apply to**.

1. **Pick a template**: choose one of yours, or **+ New template**.
2. **What it sets**: see which fields the template fills. Press **Change** to edit it or **Remove** to delete it.
3. **Apply to**: fill those fields in on resources you already have.

## Make one

1. Press **New template**.
2. Press **Use the Tes example** or **Use the TPT example** to start from a worked example, or start blank. The Tes example uses British wording (pupils, year groups); the TPT example uses American wording (students, grade levels).
3. Give it a **Name** you will recognise.
4. Under **Written for**, choose **Any marketplace**, or one marketplace to add that marketplace's own questions too.
5. Write a **Template note** if you like. It is a note to yourself about when to use the template. Buyers never see it.
6. Fill in only the fields you always answer the same way. Leave the rest empty, and the resource form will ask for them as usual.
7. Press **Save template**.

An example is only a starting point. Replace its words with your own before you save: whatever is left in is published exactly as written.

If you pressed an example by mistake, press **Undo** on the line that says what it filled in. Undo brings back what you had before and removes anything you changed since.

## The description in a template

A template's description is written in Markdown: plain text with marks in it, such as `**bold**` and a `-` at the start of a list line. The **B**, **I**, **•** and **1.** buttons add the marks for you.

When the template fills in a resource written in rich text, the marks become real bold, italics and lists.

## Use one on a new resource

1. Open **Catalogue → New resource**.
2. Choose the template under **Optional: start from a template**.
3. Check every filled-in field before you create the resource.

A template only fills empty fields there, so nothing you have typed is replaced. See [Creating a resource](/guides/new-resource).

## Apply one to resources you have

1. Pick the template.
2. In **Apply to**, choose **Fill empty fields** to keep what each resource already has, or **Replace what's there** to let the template's answers win.
3. Tick the resources, or tick **Tick these** to take the whole page.
4. Press **Preview**. The table shows what would happen to each resource: **Will change** (and which fields), **Unchanged** or **Blocked** (and why).
5. Press **Apply to** and the number shown.

Nothing changes until you press Apply. To fill a whole collection in its own order, use **Apply a template…** on the collection instead. See [Labels and collections](/guides/labels-and-collections).

## Marketplace words

The **Marketplace words** tab on the same page sets how your own words show on each marketplace. See [Target term rules](/guides/target-terms).
