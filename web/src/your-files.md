# Where your files live

Your listing files stay on your own devices. Teachouse records which device holds which file and sends a file only when you publish to a marketplace.

## See which device holds a file

1. Open **Catalogue → Your devices' files**.
2. Search for the resource.
3. Read the device name beside each file.

## Add a device

1. Install the desktop app on the second device and sign in.
2. Leave it running once so it reports the files it can see.
3. Refresh **Your devices' files**.

## Move a file to another device

1. Copy the file across yourself, keeping the same name.
2. Open the desktop app on the new device.
3. Check the resource lists the new device before you publish.

## Publishing needs the device awake

A publish waits for a device that holds the file. Keep that device on and signed in while a run is going.

## Deleting

Removing a resource in Teachouse removes the record, not your file. Delete the file yourself if you want it gone.

## The one exception

A thumbnail is stored by Teachouse so the console and the marketplace can show it without waking your device. Everything a buyer downloads stays with you.
